# Q1 Cinema — Пульт со смартфона для проектора Umiio Q1 (Android 9)

Приложение создано специально для проектора без физического пульта:
- **Автозапуск при включении проектора** — нажал кнопку питания на корпусе, и на стене сразу появляется QR-код.
- **Никаких лагов Miracast** — телефон не стримит экран, а работает как Wi-Fi пульт, тачпад и клавиатура.
- **Два режима воспроизведения**:
  1. **Нативный плеер (ExoPlayer)** — аппаратное декодирование для прямых ссылок (`.m3u8`, `.mp4`, `.mkv`) на 2 ГБ ОЗУ.
  2. **Браузер с AdBlock + Перехватчик потока** — открывает киносайты/YouTube/VK, вырезает рекламу и автоматически предлагает перехватить найденный `.m3u8`-поток в нативный плеер.
- **Виртуальный тачпад и ввод текста** — заменяет потерянный пульт полностью.

## Как собрать `.apk` за 2 минуты без установки программ на ПК
1. Создай пустой репозиторий на [GitHub](https://github.com/new).
2. Загрузи в него все файлы из этого архива (включая скрытую папку `.github`).
3. Перейди во вкладку **Actions** в репозитории → дождись зелёной галочки (~2 минуты) → скачай артефакт **UmiioQ1-Cinema-APK**.

## Первая установка без пульта
1. Подключи к USB-порту проектора любую обычную компьютерную мышку.
2. Скопируй `app-debug.apk` на флешку, вставь в проектор и установи через встроенный проводник.
3. Открой **Q1 Cinema** один раз — дальше приложение будет запускаться само при каждом включении проектора, а мышка больше не понадобится.
